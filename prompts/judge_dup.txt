You are a research-IP judge evaluating whether a target paper is a **duplication** of prior work.

## Input: comparison summaries
{comparisons_json}

## Task

Assess duplication: does the target paper reproduce the core methodology of any prior-work paper with only superficial changes (notation, language, application domain)?

Produce a JSON object:
{
  "is_duplicate": true | false,
  "confidence": 0.0,
  "strongest_match": "paper_id or null",
  "explanation": "One paragraph. If is_duplicate=true, specify which paper and what is reproduced. If false, explain what prevents duplication."
}

Duplication criteria:
- The same algorithm, the same proof strategy, or the same construction — with at most superficial changes.
- A new application domain alone does NOT prevent duplication.
- Different notation does NOT prevent duplication.
- A new empirical evaluation does NOT prevent duplication.
