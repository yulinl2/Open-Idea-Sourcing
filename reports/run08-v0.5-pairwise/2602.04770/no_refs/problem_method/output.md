# Problem Formulation

## Notation and Setup

Let $\mathcal{X} \subseteq \mathbb{R}^d$ denote the data space and $p_{\text{data}}(x)$ the unknown target data distribution over $\mathcal{X}$. We consider a simple prior distribution $p_0(z)$ over a latent space $\mathcal{Z} \subseteq \mathbb{R}^d$, typically chosen as $p_0(z) = \mathcal{N}(0, I)$. Our goal is to learn a deterministic mapping $T_\theta: \mathcal{Z} \to \mathcal{X}$ parameterized by $\theta$ such that if $z \sim p_0(z)$, then $T_\theta(z)$ follows approximately the target distribution $p_{\text{data}}(x)$.

Let $p_\theta(x)$ denote the distribution of samples generated by the pushforward $T_\theta \# p_0$, where $(T_\theta \# p_0)(A) = p_0(T_\theta^{-1}(A))$ for any measurable set $A \subseteq \mathcal{X}$. We define the transport map $T_\theta$ as a deep neural network with parameters $\theta \in \Theta$.

For conditional generation, we extend our notation to include conditioning variables $c \in \mathcal{C}$, where $p_{\text{data}}(x|c)$ represents the conditional target distribution and $T_\theta(z, c): \mathcal{Z} \times \mathcal{C} \to \mathcal{X}$ is the conditional transport map.

## Formal Problem Statement

**Given:** 
- A dataset $\mathcal{D} = \{x_i\}_{i=1}^n$ with $x_i \sim p_{\text{data}}(x)$
- A simple prior distribution $p_0(z)$ 
- A parametric family of transport maps $\{T_\theta\}_{\theta \in \Theta}$

**Find:** Parameters $\theta^*$ such that the pushforward distribution $p_{\theta^*}(x) = T_{\theta^*} \# p_0$ approximates $p_{\text{data}}(x)$

**Guarantee:** The learned mapping $T_{\theta^*}$ generates high-quality samples in a single forward pass while minimizing the distributional discrepancy between $p_{\theta^*}(x)$ and $p_{\text{data}}(x)$.

## Objective Formulation

The core challenge lies in defining a tractable objective that measures distributional discrepancy without requiring adversarial training or iterative sampling procedures. We formulate this as an optimal transport problem, seeking to minimize the 2-Wasserstein distance:

$$W_2^2(p_{\text{data}}, p_\theta) = \inf_{\gamma \in \Pi(p_{\text{data}}, p_\theta)} \mathbb{E}_{(x,y) \sim \gamma}[\|x - y\|_2^2]$$

where $\Pi(p_{\text{data}}, p_\theta)$ denotes the set of all joint distributions with marginals $p_{\text{data}}$ and $p_\theta$.

However, computing this distance directly is intractable. Instead, we leverage the dual formulation and approximate it through a regression-based objective. Our training objective becomes:

$$\mathcal{L}(\theta) = \mathbb{E}_{x \sim p_{\text{data}}} \mathbb{E}_{z \sim p_0} \left[ \|x - T_\theta(z)\|_2^2 + \lambda \mathcal{R}(\theta) \right]$$

where $\mathcal{R}(\theta)$ is a regularization term and $\lambda > 0$ is a regularization parameter.

## Technical Assumptions

**Assumption 1 (Regularity):** The target distribution $p_{\text{data}}$ has finite second moments, i.e., $\mathbb{E}_{x \sim p_{\text{data}}}[\|x\|_2^2] < \infty$.

**Assumption 2 (Universal Approximation):** The neural network family $\{T_\theta\}_{\theta \in \Theta}$ has sufficient capacity to approximate the optimal transport map between $p_0$ and $p_{\text{data}}$.

**Assumption 3 (Optimal Transport):** There exists an optimal transport map $T^*: \mathcal{Z} \to \mathcal{X}$ such that $T^* \# p_0 = p_{\text{data}}$ and this map is unique almost everywhere.

**Assumption 4 (Smoothness):** The optimal transport map $T^*$ is sufficiently smooth to be well-approximated by neural networks.

These assumptions are justified by optimal transport theory, which guarantees the existence and uniqueness of optimal transport maps under mild conditions, and by universal approximation theorems for neural networks.

# Methodology

## High-Level Approach

Our approach, which we term **Rectified Flow**, is based on the insight that we can learn the optimal transport map by simulating a continuous-time interpolation between the prior and data distributions. Rather than learning the map directly, we learn the velocity field of a flow that transports samples from $p_0$ to $p_{\text{data}}$ along straight-line trajectories.

The key innovation is to parameterize the velocity field such that the resulting flow follows rectified (straight-line) paths, which can be simulated exactly in a single step at inference time. This eliminates the need for iterative numerical integration while maintaining the expressiveness of continuous normalizing flows.

## Core Algorithm

### Rectified Flow Formulation

We define a time-dependent vector field $v_\theta(x, t): \mathcal{X} \times [0,1] \to \mathbb{R}^d$ and consider the ordinary differential equation (ODE):

$$\frac{dx}{dt} = v_\theta(x, t), \quad x(0) \sim p_0$$

The solution at time $t=1$ gives us samples from our generated distribution: $x(1) \sim p_\theta$.

For rectified flows, we specifically parameterize the velocity field to encourage straight-line trajectories. Given a data point $x_1 \sim p_{\text{data}}$ and noise $x_0 \sim p_0$, the straight-line path is:

$$x_t = (1-t)x_0 + tx_1 = x_0 + t(x_1 - x_0)$$

The corresponding velocity field is constant along this trajectory:

$$v_t^*(x_t) = x_1 - x_0$$

### Training Objective

We train the neural network $v_\theta$ to match this target velocity field by minimizing:

$$\mathcal{L}(\theta) = \mathbb{E}_{t \sim \mathcal{U}[0,1]} \mathbb{E}_{x_0 \sim p_0} \mathbb{E}_{x_1 \sim p_{\text{data}}} \left[ \|v_\theta(x_t, t) - (x_1 - x_0)\|_2^2 \right]$$

where $x_t = (1-t)x_0 + tx_1$ and $\mathcal{U}[0,1]$ denotes the uniform distribution on $[0,1]$.

### Algorithm

```
Algorithm: Rectified Flow Training

Input: Dataset D = {x_i}_{i=1}^n, batch size B, learning rate η
Output: Trained velocity network v_θ

1. Initialize network parameters θ
2. For each training iteration:
   a. Sample batch {x_1^(i)}_{i=1}^B from dataset D
   b. Sample batch {x_0^(i)}_{i=1}^B from prior p_0
   c. Sample batch {t^(i)}_{i=1}^B from U[0,1]
   d. Compute interpolants: x_t^(i) = (1-t^(i))x_0^(i) + t^(i)x_1^(i)
   e. Compute target velocities: v_target^(i) = x_1^(i) - x_0^(i)
   f. Forward pass: v_pred^(i) = v_θ(x_t^(i), t^(i))
   g. Compute loss: L = (1/B) Σ_i ||v_pred^(i) - v_target^(i)||_2^2
   h. Update parameters: θ ← θ - η ∇_θ L
3. Return θ
```

### Generation Procedure

At inference time, generation requires only a single forward pass:

```
Algorithm: Rectified Flow Generation

Input: Trained velocity network v_θ, noise sample z ~ p_0
Output: Generated sample x

1. Set x_0 = z
2. Compute velocity: v = v_θ(x_0, 0)
3. Generate sample: x = x_0 + v
4. Return x
```

## Design Justifications

**Straight-line parameterization:** By encouraging straight-line trajectories between noise and data, we minimize the path length in the 2-Wasserstein sense, which is optimal for quadratic cost functions. This connects directly to optimal transport theory.

**Time-uniform sampling:** Sampling time $t$ uniformly from $[0,1]$ ensures that the learned velocity field is accurate across the entire trajectory, not just at the endpoints.

**Regression objective:** Unlike adversarial training, our regression-based objective is stable and does not suffer from mode collapse, as we directly supervise the velocity field with ground-truth targets.

## Theoretical Properties

**Theorem 1 (Consistency):** Under Assumptions 1-4, as the network capacity increases and training data approaches infinity, the learned velocity field $v_\theta$ converges to the optimal velocity field $v^*$ that transports $p_0$ to $p_{\text{data}}$ along straight lines.

**Theorem 2 (Single-step optimality):** If the learned velocity field $v_\theta$ perfectly matches the target velocity field, then the single-step generation procedure $x = x_0 + v_\theta(x_0, 0)$ produces samples exactly distributed according to $p_{\text{data}}$.

**Corollary 1 (Wasserstein optimality):** The straight-line transport minimizes the 2-Wasserstein distance between $p_0$ and $p_{\text{data}}$ among all transport maps.

## Computational Complexity

**Training complexity:** Each training iteration requires $O(Bd)$ operations for the forward pass through the velocity network, where $B$ is batch size and $d$ is dimensionality. The overall training complexity is $O(TBd)$ for $T$ training iterations.

**Generation complexity:** Generation requires exactly one forward pass through the velocity network, giving $O(d)$ complexity per sample, which is optimal for any generative model.

**Memory complexity:** The method requires storing only the velocity network parameters and has the same memory footprint as standard neural networks, with no additional memory overhead for iterative sampling procedures.
